# Nightreign-Save-Manager

A small, lightweight Windows Forms (WinForms) application designed to help you easily manage, back up, and restore your save files for **Elden Ring: Nightreign**.

### Installation & Usage
1. Download the latest `.zip` archive from the [Releases](../../releases) tab.
2. Extract the files to any convenient folder on your PC.
3. Run `NightreignSaveManager.exe`.
4. Manage your saves directly from the app. 
   > **Note:** Always ensure the game is completely closed before restoring a save file!

## ⚠️ Disclaimer
This is an unofficial, fan-made utility.
